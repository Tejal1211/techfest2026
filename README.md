# 🚀 TECHFEST 2026 – 3D Interactive Experience

A futuristic 3D interactive Techfest website built using **Three.js**, **GSAP**, **HTML**, **CSS**, and **JavaScript**. The project delivers an immersive cyberpunk-inspired experience featuring 3D animations, holographic UI elements, smooth scroll effects, and interactive user experiences.

## 🌟 Features

* Interactive 3D Hero Section
* Futuristic Cyborg-Inspired Design
* Three.js Powered 3D Elements
* GSAP Scroll Animations
* Smooth Page Transitions
* Holographic UI Components
* Dynamic Particle Effects
* Interactive Technology Showcase
* Responsive Design for Mobile, Tablet, and Desktop
* Modern Cyberpunk Aesthetic
* FAQ Accordion
* Animated Timeline
* Interactive Event Highlights
* Registration Call-to-Action Section

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Three.js
* GSAP
* ScrollTrigger

## 💻 Installation

1. Clone the repository:

```bash

```

2. Open the project folder:

```bash
cd techfest2026
```

3. Open `index.html` in your browser.
